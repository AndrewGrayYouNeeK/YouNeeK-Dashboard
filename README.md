# YouNeeK Dashboard

A personal dashboard built with **Vite + React + TypeScript**.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build for production

```bash
npm run build
npm run preview
```

## Pages

- **Overview** — stat cards, activity chart, recent activity feed
- **Analytics** — placeholder for charts and metrics
- **Projects** — placeholder for your projects list
- **Settings** — placeholder for account settings

## Stack

- React 18
- TypeScript
- Vite 5
- CSS Modules
