# YouNeeK Dashboard

Personal dashboard for YouNeeK. Vite + React + TypeScript.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## What is connected

- **Overview** — live product count, repo count, open issues, last push. Pulls `AndrewGrayYouNeeK` public repos from the GitHub API on load.
- **Analytics** — language mix and push weeks from those repos.
- **Projects** — pinned YouNeeK products (Pro Radar, Time, Care, youneek.xyz, Satellite Tracker, REMNANT, 3I/ATLAS, Air Traffic, The Architects, Agent World, Cloudripper, Neural Forge) plus every other repo.
- **Settings** — optional GitHub token, stored only in this browser, to include private repos.

Live sites: https://youneekproradar.com · https://youneektime.com · https://youneekcare.com · https://youneek.xyz
